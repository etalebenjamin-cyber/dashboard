# Pulse

Le rythme de ta journée — PWA standalone.

Tâches, habitudes, finances, focus, humeur, eau, énergie, routines, journal, objectifs, comptes à rebours, récompenses.

## Installation iPhone
1. Ouvre l'URL dans Safari
2. Bouton Partage → Sur l'écran d'accueil

## Installation Mac
1. Ouvre l'URL dans Safari
2. Menu Fichier → Ajouter au Dock

Mode sombre auto qui suit ton système. Marche offline une fois installée.
