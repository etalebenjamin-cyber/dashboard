# Dashboard Perso

Tableau de bord quotidien — tâches, habitudes, finances, focus, humeur, etc.

PWA standalone : les données restent dans le navigateur (localStorage), aucun serveur requis.

## Installation sur iPhone
1. Ouvre l'URL dans Safari
2. Bouton Partage → Sur l'écran d'accueil

## Installation sur Mac
1. Ouvre l'URL dans Safari
2. Menu Fichier → Ajouter au Dock

Mode sombre auto qui suit ton système.
